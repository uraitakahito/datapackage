Fiscal Data Package は、財政データを公開・利用するための軽量かつ利用者本位のフォーマットである。Fiscal data package はシンプルで汎用的な部品から構成される。それらは通常の表計算ソフトウェアで作成でき、あらゆる環境で利用できる。
